# Reconciliation

Reconcliation is one kind of submissions, allows user to match the actual inventory stock with in-app numbers. Sell transaction is created automatically based on the diff.

## How-it-works

1. Inventory snapshot is taken when reconciliation starts.
2. Sell transactions generated by reconciliation are inserted at the same created_at of the reconciliation start, which is `inventory_submissions.created_at`.

## Safety Checks

During reconciliation:

- Pre-operation checks:
  - Purchase Order receives are not affected. Stock received during reconciliation is still counted and updated into app stock, wihtout affecting the reconciliation, because the sell quantity bases on snapshot at reconciliation start. Important note: it's user responsibility to NOT count newly received stocks in the reconciliation.
  - Dispose/Transfer (Out) submissions can be created (in future improvements, this operation will be blocked during reconciliation of an inventory)
